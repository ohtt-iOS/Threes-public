# Threes — support & privacy

Public pages for the Threes iOS app (3-second clips × 3, one vertical video diary).

- Support: https://ohtt-ios.github.io/Threes-public/  (per language: `/<lang>/`, e.g. `/ko/`, `/ja/`)
- Privacy policy: https://ohtt-ios.github.io/Threes-public/privacy.html  (per language: `/<lang>/privacy.html`)
- Questions or bugs: [open an issue](https://github.com/ohtt-iOS/Threes-public/issues)

Languages: en · ko · ja · zh-Hans · zh-Hant · vi · es · pt-BR · th · id.
Edit the text in `build.py` (`CONTENT`) and run `python3 build.py`; the HTML files are generated.
